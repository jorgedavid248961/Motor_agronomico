# Motor_agronomico

Motor agronómico Space Wanderers 4.1 (NASA Space Apps 2026) expuesto como API con FastAPI + PostgreSQL.

- `motor_agronomico_v41.py`: motor, interfaz Streamlit y autopruebas.
- `cuaderno_agronomico_unificado_2.3.json`: reglas, interacciones y prácticas.
- `territorial_index_v41.json`: índice territorial por celda (~1 km²) para la interfaz Streamlit y la CLI.
- `app/`: API. Toma los datos del territorio de la API canónica (`TERRITORIAL_API_URL`). Uso, endpoints y despliegue en [README_API.md](README_API.md).
